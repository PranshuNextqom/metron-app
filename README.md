# Metron app for Android

The Metron collection app for agents.

### [⬇ Download Metron for Android](https://github.com/PranshuNextqom/metron-app/releases/latest/download/Metron.apk)

This link always gives the newest version.

## How to install

1. Open the download link on your **Android phone**. Chrome saves `Metron.apk`.
2. Open the downloaded file. If Android asks, allow Chrome to install apps (**Install unknown apps → Allow**).
3. Tap **Install**. If the old Metron app is on the phone, tap **Update** — it replaces the old app.
4. If Play Protect warns you, tap **More details → Install anyway**.
5. Open Metron and sign in with your usual email and password.
6. Allow **Camera** and **Location** when asked. Absent photos need both.

The app is for Android only. It does not run on iPhone.

## Updates

You only install by hand once. After that, Metron checks for a new version every time you open it. When one is out it shows **Update available**: tap **Update now**, wait for the download, then tap **Install**.

The first time, Android asks whether Metron may install apps. Tap **Settings → Allow from this source**, go back, and tap **Install** again.

## Versions

Every version, with what changed, is on the [Releases](https://github.com/PranshuNextqom/metron-app/releases) page.

For help, ask your Metron admin.
